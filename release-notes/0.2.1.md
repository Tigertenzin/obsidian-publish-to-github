A small release ahead of submitting the plugin to the Obsidian community plugin directory.

## Changed

- **The command is now "Publish current note".** Obsidian shows a plugin's commands prefixed with its name, so the old name read "Publish to GitHub: Publish to GitHub" in the command palette. Hotkeys you've assigned keep working.

## Added

- **A LICENSE file.** The plugin was already MIT-licensed; the license text is now in the repository.
- **A Disclosures section in the README**, stating plainly that the plugin needs a GitHub account and token, and that it talks only to GitHub's API.

## Fixed

- **README corrections:** note embeds are converted to plain text rather than left alone, an unchanged post can still upload changed images, and a garbled paragraph about publishing conflicts is untangled.

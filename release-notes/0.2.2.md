**Publish to GitHub is now called Static Site Publisher.**

A name that says who the plugin is for — anyone whose site is built from a GitHub repository, with Eleventy, Hugo, Jekyll or similar — and that stands apart from the other GitHub publishing plugins ahead of submitting to the Obsidian community plugin directory.

Only the name has changed. The plugin's ID, its folder in your vault, your settings, your access token, your remembered filenames and your hotkeys all stay exactly as they were. In the command palette, the command now reads "Static Site Publisher: Publish current note".

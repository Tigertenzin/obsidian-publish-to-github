**Publish to GitHub is now Static Site Publisher, all the way through.** 0.2.2 changed the name you see; this release changes the plugin's ID to match, from `publish-to-github` to `static-site-publisher`, ahead of submitting it to the Obsidian community plugin directory, where an ID can never change once listed.

## Upgrading

The new ID makes this a separate plugin as far as Obsidian is concerned, so it installs alongside Publish to GitHub rather than replacing it:

1. **Install Static Site Publisher and enable it.** On its first load it imports everything from Publish to GitHub: the connection, property lists, break and attachment settings, and the filenames your notes were last published under. It also copies your access token to its own secret, `static-site-publisher-token`. A notice confirms the import.
2. **Uninstall Publish to GitHub.**
3. **Re-assign your publishing hotkey,** if you had one. Hotkeys belong to a plugin's ID, so they don't carry over.

With BRAT, add `Tigertenzin/obsidian-static-site-publisher`; the repository has been renamed to match.

The old secret, `publish-to-github-token`, is left in Obsidian's secret storage in case you need the old plugin again. Once you don't, remove it there.

## Changed

- The plugin's ID is now `static-site-publisher`, and its folder is `.obsidian/plugins/static-site-publisher`.
- The command's ID is now `publish-current-note`.
- The review window is titled "Publish note".
- The access token is kept under the secret name `static-site-publisher-token`.
